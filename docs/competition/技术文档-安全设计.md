## 1. 资产与信任范围

保护账户/账务、授权参数、交易终态、用户归属、上下文证据、模型额度和凭证。浏览器文本、商户文本、模型输出均为不可信输入；服务器会话、受控业务查询和银行模拟回执是对应范围内的权威来源。模型不能提供授权状态或伪造交易成功。

| 威胁 | 现有控制 | 剩余边界 |
|---|---|---|
| 提示注入绕过授权 | 白名单工具，模型只查询/预览；执行重新核验授权 | 任意注入识别尚无全覆盖证明，模型仍可能误解或误拒 |
| 编造数字、账户或回执 | 来源事实与程序计算、事实/语义核验，失败安全解释 | 同模型审核仍可能漏判；自由回答质量部分通过 |
| 跨用户查询或确认 | 服务器会话归属、Service条件、CSRF/Origin、原动作归属 | 当前身份为合成u1，未接真实登录 |
| 改参后旧授权继续有效 | 原payload_hash/版本绑定，修改后失效，提交前再判定 | MySQL迁移哈希/时间语义待验证 |
| 重复执行和结果未知 | 稳定action/期次唯一键、查原动作、短事务与账务核对 | 外部银行未接入；图恢复不能保证外部exactly-once |
| 验证猜测或额度绕过 | 验证失败计数/锁定、日累计占用、有效期和提交复核 | 验证为DEMO，连续Agent失败综合熔断待补 |
| 模型费用放大 | 实际发送前共享预算、失败计数、请求/Token记录 | 当前预算是本地调试保护，非多租户运营计费 |

## 2. 权限与用户授权

绿色查询、黄色确认、红色强验证采用独立业务政策。银行端确定risk与required_assurance，模型“用户同意”不产生grant。授权绑定对象、参数哈希、归属、策略与时效，提交前校验余额/日累计与验证证明。验证码展示与校验为本地演示，不称为短信、人脸或U盾接入。

网页会话Cookie使用HttpOnly/SameSite，非GET要求CSRF及Origin匹配；当前用于本地合成演示，不替代真实身份体系。数据库SQL由MyBatis绑定参数，Controller/Agent不注入Mapper。

## 3. 账务、副作用与审计

资金、分录、流水和终态同一事务；模型/银行网络请求不持长事务。未知请求先观察原动作，不能改ID重发。审计与风险事件记录决策与状态；原链路关联仍可加强，不能宣称已有完整分布式追踪。

API key只从本机环境读取，发布材料不包含密钥、Cookie、OTP和内部凭证。候选使用合成数据，不能据此声称已有真实个人数据脱敏和数据治理能力。API模型调用的具体数据发送范围未来接入真实客户前需另评估。

## 4. v0.7新增安全协议（设计待实现）

Java为唯一网页入口；Python使用内部服务认证，无浏览器Cookie。银行回调能力token高熵、摘要落库、绑定原轮/用户/scope/expiry；Python只访问Agent库。令牌不是资金授权。续签与撤销同事务，整轮工具quota不重置；只读接口拒绝authorize/submit。

Java唯一contextVersion，旧resume不得绕过reset/改口。模型调用有稳定effect编号、持久化回执与发送前预算；SENDING未知暂停。对账检查租约/未ACK，冲突冻结。旧版本和新候选库/端口隔离，迁移先列级diff与哈希核对。

首阶段未开放模型生成代码执行或shell工具，因此不引入该执行通道；通用受限代码沙箱尚未实现，不能把工具白名单直接称为代码沙箱。远程部署、TLS、真实认证和MFA均需后续独立设计与验收。

## M3 阶段安全边界

Java内部回调需服务Bearer身份与短期X-Agent-Grant，工具身份只来自持久化grant，不信任模型userId。四项只读scope、本轮最多八个工具回执；续签不重置本轮工具上限。模型预算预留要求活跃原轮/版本；已撤销grant仅可证明原预留的用量记录归属，不能获得工具或新预留。

Python只存可信请求投影，不存raw grant、模型key或Cookie；凭证只在本机环境/运行内存。运行事件只保存节点与状态码，不保存推理链。MySQL账号分库DML，银行资金与交易权威始终在Java。网页轮询读取原requestId，绝不把慢响应转成新模型调用。

API请求/响应64KiB，银行事实回调256KiB；模型输出最多2048tokens，适配器无自动重试。调用结果先写effect再交图checkpoint。租约丢失、版本冲突、无效事实、修正耗尽和模型UNKNOWN均停止自动完成。当前候选为loopback、合成身份/数据和模拟强验证，未证明生产TLS、真实登录、跨实例一致性或真实银行安全。

程序核验具体金额、日期、引用与执行结论，并不提供完整语义证明。商户/备注被视为不可信数据；只读白名单控制执行权，不能宣称覆盖所有提示注入。模型usage已保存而Java记录回调失败时，须按原reservation核对记录，不能为了用量统计重发模型。
