# iFinD MCP 官方能力核验与 SafeBank 接入边界

核验日期：2026-10-14。范围：公开页面阅读，不登录、不注册、不申请试用、不调用 `tools/list` 或金融数据工具，不使用付费账户。本文件为方案调研，未实施接入，是否新增基金功能待用户选择。

## 结论

iFinD MCP 可作为 SafeBank 的可选外部只读数据源，支撑“指定基金的资料与风险事实查询/对比”。官网当前确认有基金、公告等数据域及免费试用入口；但免费试用的时长、额度、实际基金权限及付费金额没有在本次取得的公开正文中核实。不能把它描述成必然纯付费，也不能承诺免费长期运行。[官网](https://mcp.51ifind.com/?syncCookieTimes=1)

基金查询适合补充银行服务演示的金融事实能力；它本身不构成基金申购、赎回、自动投资或完整理财操作。SafeBank 现有账单、代扣、受控资金操作仍是独立业务链。本建议依据本项目 `AGENTS.md` 中“模型只查询或生成预览，用户逐动作授权”的边界作工程推断。

## 与传统数据接口严格区分

同花顺传统数据接口官方文档确实列出免费、试用、正式三种账号及各自数据量/历史区间；免费版需要 iFinD 账号，EDB 权限与其他函数有区别。这个页面没有证明传统免费权益自动覆盖 MCP。[传统数据接口权限说明](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/help-center/permission.html)

传统 HTTP 接口的 token、函数说明也不能用来推定 MCP 的认证方案或基金 schema。原笔记所引第三方工具名、SSE/HTTP 建议、端口和认证写法只能当核验线索，不能成为实现合同。

## 建议的最小接入边界（工程建议，未实施）

1. 产品入口只接受明确基金代码/名称与有限日期范围。名称存在 A/C 类等歧义时先确定份额类别；支持指定一只或两只基金的事实对比，不提供全市场选基排序。
2. 仅在账户实际支持时查询基金类型、净值日期、历史收益/回撤的明确区间、最近披露持仓及集中度、基金经理与公告。未返回的回撤、评级或“风险等级”不猜测；历史表现不能写成未来收益保证，公告未命中也不能写成“没有风险”。
3. 在 Python 工具适配层注册小范围只读白名单，实际工具名和 schema 必须来自官方配置及授权后的工具发现。设置超时、有限重试、最大查询数/输出长度和额度上限；没有凭证、权限不足或额度耗尽时展示能力不可用。
4. 返回事实须携带基金身份、数据日期/披露期、单位、来源及查询时间；如果自行计算回撤或持仓集中度，明确计算区间、方法与原始数据范围。实时查询与离线演示数据分开标识。
5. 只将基金查询条件送至数据源，不发送账单、身份、账户、代扣合同或用户完整聊天。第三方公告/资讯文本作为数据处理，不能改变工具白名单或触发银行动作。
6. 该查询入口不创建申购、赎回、转账、调仓、扣款或自动任务，不把事实对比写成个性化适当性结论；与现有逐动作授权和交易状态恢复机制保持分离。
7. 未取得缓存/演示授权前，不默认把 iFinD 原始响应写入 MySQL、训练集、公开仓库或共享知识库。可以先用明确标注的合成基金材料验证界面和只读隔离；实际数据展示是否允许需单独核实。

真实接入前只需补齐三组证据：当前账户免费/试用额度和收费机制；目标基金工具配置/schema/transport及只读能力；内部使用、模型传输与演示展示的数据授权。若无法取得，基金功能保持可选，不作为比赛主链路必需依赖。
