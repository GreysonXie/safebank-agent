# v0.6 业务记忆实施与候选验收

2026-10-10。本轮按已批准设计在 `feature/v0.6-business-context` 隔离实现。用户随后选择推荐的方式：保留候选分支与隔离目录，先供团队试用。原开发分支与 8096 页面保留；新候选业务端口 8110、模拟验证台 8111。暂不合并或推送。

## 已实现

四张上下文表与 MyBatis Mapper 支持业务意图、带来源的参数、银行查询依据和轮次回执。显示历史最多四轮，业务槽独立保留；活动上下文有效期七天。服务器区分客户明确选择、模型提案与银行确认数据，记忆不会授予资金权限。

可承接月份和交易追问、澄清重名收款人、记录缺失参数、处理改口和暂停。修改金额、收款人、来源或计划日期会作废未提交的原动作；UNKNOWN/PENDING 必须先核对原动作。相同未完成储蓄提案沿用原任务，新参数不会悄悄另建重复任务。原授权、验证码、日累计和账务核验接口继续使用。

聊天可带 conversationId/requestId/expectedContextVersion；相同请求重放原响应，冲突不自动重新创建。刷新用 GET 恢复历史和原银行对象引用，断线重试复用原请求。清空对话草案不会暗中取消银行动作。界面保持左侧导航、中间业务、右侧对话，手机对话位于业务内容下方。

确认查询的原始数据、纳秒查询时间、动作 ID 和本人银行侧查询范围进入回答事实目录。快照不能冒充当前状态；查询表后续改变不会改写原回执。

## 本地验证与独立审查

基线 242 项；首次整版 263 项中旧测试仍断言总表数为 20，现按新增四表改为 24，资金断言保留。五项独立审查 Important 均形成真实失败用例，再修正到 GREEN：整数分 JSON 类型匹配、否定式收款人选择、修改参数后旧授权、跨轮重复工作流、原查询观察信息。定向 55 项通过。

真实模型调试后另有一次必要修正：比较兜底原先只收到本轮新查月份，现合并历史与新依据；程序提供按完整分类合计推导的零值、差额和差额绝对值，比较回答不再用单月总览替代。对应两项 RED→GREEN，连同事实核验与对话定向 45 项通过。最终整版结果见 evidence/2026-10-10-business-context/verification.json。

浏览器插件未提供，使用本机 Playwright/Edge。模拟契约覆盖刷新不发聊天、断线精确重试、双标签冲突、1440/390 布局、零 pageerror。实际候选另验证真实 GET 恢复和导航，零聊天请求；重启后的新内存实例单独检查页面。截图位于忽略目录 target/context-candidate-ui-qa。

计划中较细的数据库异常组合和精确七天边界尚未全部单列测试；本轮实际覆盖范围以上述测试和证据为准，未宣称所有输入均已验证。旧文件库未迁移，候选使用独立合成内存库，进程重启会重置合成数据和上下文。

## 真实 DeepSeek 调试：部分通过

只执行一组、三轮合成账单问答，不提交资金动作。第一轮连接在受限 Windows 账户下失败并停止；联网账户启动独立候选后继续同一账本，没有删除或重置次数。PowerShell 登记时间转换的八小时时差已修正，重启仅匹配登记 PID、启动时间、运行 JAR 路径和 SHA256；Git 兼容使用单次 safe.directory，不修改全局设置。

| 问题 | 真实结果 | 判定 |
|---|---|---|
| 九月最重要的支出发现 | 手写“八成”被事实核验拦截，最终安全兜底较长 | 简短自由回答未通过 |
| 只核对最大那笔支出 | 承接九月租金，给出商户、日期、金额和合同/收据核对建议，经语义审核通过 | 针对性回答通过 |
| 与八月比最大类别变化 | 数字与计算引用修正消耗预算，旧兜底返回八月总览 | 当时未通过；本地已修正分类事实与比较兜底，未追加付费复测 |

因此本轮不能称为真实自然对话全部通过。重名转账、代扣确认、联合储蓄的真实模型组没有执行，本地边界已验证。尚待小范围真人反馈及回答首次核验通过率改进。

## 用量与启动

总预留 11/20：10 次成功供应商响应、1 次连接失败；剩余 9。三轮成功请求为 4、2、4 次，其中生成 9 次、审核 1 次。供应商报告输入 69,862 Token、输出 1,640 Token、合计 71,502；输入缓存命中 44,032、未命中 25,830。失败尝试 usage 未知。不能据此推算人民币扣费。

共享账本固定在主项目 `.superpowers/deepseek-v06-debug/20261010-v06-context.json`。HTTP 发送前原子预留，失败不退还；跨进程/重启累计，坏账本拒绝发送。第 21 次发送阻断用本地 fake HTTP 验证，不消耗真实额度。候选之后的人手聊天同样消耗剩余次数，本轮不再自动追加调试。

在此隔离目录运行 `./run.ps1 package` 后，`./start-context-demo.ps1` 默认离线；在线需显式 `-Online -KeyFile` 指向本机密钥文件。已登记候选可用 `restart-context-demo.ps1` 核验后重启。业务地址 htt<LOCAL_PATH> 保持原 v0.5。

密钥与验证凭据仅在本机忽略目录或进程环境，公开证据不含密钥、会话 Cookie、验证码或验证台凭据。此版仍为单实例、合成身份和模拟银行，不包含通用 DAG、真实 MFA 或官方银行接入。
