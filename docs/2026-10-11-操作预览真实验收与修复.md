## 修正与免费验证

- 澄清 interrupt 保存时保留当前轮已验证事实回执，避免最终校验引用失效。每轮新计划仍清空旧回执。
- 转账事实投影补充 Java 已核对的本人收款人姓名和备注；规划提示使用单个检索词，不拼接姓名与备注。第三批真实规划已验证此项改善。
- 仅有对应当前预览证据时允许“已生成/准备转账或撤销预览”；仍拒绝真实执行成功，以及省略业务宾语的“已执行成功”“已经办理完成”“已经成功办理”。
- 有当前预览时，严格允许“确认无误后再从操作卡完成转账/撤销”这类后续指引。“已完成”不享受例外，模型仍无授权或执行工具。
- 撤销影响提示改用银行授权与商户合同边界，避免将假设未来状态混写为当前成功状态。最后提示词尚无新真实咨询样本，不计通过。

Java 最后 GroundedAnswer 44 项全通过，此前当前预览 MySQL 9 项也通过。Python 全套 128 项中 127 项通过、1 项 Java oracle 启动 fixture 异常；该项单独重跑通过，保留原失败日志，不表述为一次性全套通过。独立复核指出省略宾语的成功声明漏检，已据此补充防护。

最后免费回放使用两条原始模型草稿及银行回执投影，均通过实际 Java 核验器：[回放证据](evidence/2026-10-11-preview-live/offline-replay.json)。这是限定投影 fixture 验证，没有调用供应商，也不验证当前动作有效期、整图运行或客户端交付，不能替代真实连续流程验收。
