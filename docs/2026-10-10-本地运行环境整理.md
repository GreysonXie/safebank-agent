## 启停与恢复

MySQL 以后沿用 D 盘的 my.ini；不得运行 `--initialize`，不得重新执行首次种子导入。只在 3307 无监听时启动：

```powershell
$mysqlExe = '<LOCAL_PATH>'
$mysqlConfig = '<LOCAL_PATH>'
if (Get-NetTCPConnection -LocalPort 3307 -State Listen -ErrorAction SilentlyContinue) {
    throw '3307 已占用，请先核验已有实例；不要重复启动'
}
Start-Process -FilePath $mysqlExe -ArgumentList "--defaults-file=$mysqlConfig" -WindowStyle Hidden -PassThru
```

此命令只启动进程；成功标志是数据库连通及候选应用的 schema 校验通过。8130 沿用项目 `start-mysql-demo.ps1`，所需数据库凭证从本机环境配置读取，不写入命令行或提交。当前本机私有启动配置已更新到 D 盘。

备份包含 `bank.sql`、`foundation-cold`、迁移前本机私有配置，仅在本机保留，不提交或上传。`<LOCAL_PATH>` 已关闭宽泛权限继承，只允许当前用户、SYSTEM 和管理员访问，子目录继承此限制。若需要恢复，先关闭唯一候选和 MySQL，保存恢复时的当前数据，再将冷备复制到新的 D 盘恢复目录，修正 basedir/datadir/log-error，移除 init-file，核验后启动。恢复前备份只能回到迁移时刻，不能覆盖迁移后新增业务数据。不要把正在运行的数据文件直接复制回原目录。旧 C 盘副本已清理，恢复依据是 D 盘备份。

M2 仍需建立独立候选数据库和账号；本次整理不代表 Java/Python 网关或 LangGraph 服务已经实现。
