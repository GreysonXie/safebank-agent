# 金融推荐功能与验收

日期：2026-10-27。状态：已更新本机 Docker 工作台 8134；未提交代码或对外发布。

## 使用与范围

启动 Java 服务后，从左侧「金融推荐」进入，或打开 `/?view=finance`。填写用途、风险偏好、可投入金额、使用期限、流动性和本金要求，再生成推荐。也可以从「应急备用金」「近期计划」「长期积累」快速填充后修改。

推荐卡包含匹配理由、建议持有期、起投金额、示例风险层级、同区间收益/回撤、年费率、流动性和主要风险。选择最多三个方向可查看对比表；折叠区域列出筛选规则、未入选方向及原因。修改任意偏好会清除原推荐及对比，避免沿用旧结论。储蓄入口仅切换到现有页面，用户仍须独立填写并确认计划。

参考 [iFinD MCP 首页](https://mcp.51ifind.com/?syncCookieTimes=1#/) 与文档目录的金融查询、基金优选与事实比较思路；官网基金正文未完成访问，未核实 MCP 工具 schema、账号权益、缓存和展示许可。未使用未经核实的工具名或模拟真实 API。

当前来源为 `SafeBank 本地合成产品库`，版本 `demo-finance-v1`，共七个虚构方向，编号均以 `DEMO-` 开头。数据日为 2026-09-30，收益/回撤示例区间统一为 2025-09-30 至 2026-09-30。存款未提供收益/回撤/费用数据，用 `null` 返回，页面展示「暂无数据」，不当作零。年费率不包括全部交易费用。数据、风险分层、收益和回撤不代表真实产品或 iFinD 数据，不构成投资建议。

## 规则与实现

- 风险上限：稳健为示例层级2，平衡为3，成长为4；备用金用途进一步限制为层级1。
- 先排除不符合本金要求、起投金额、建议持有期限、约定存期、取用等待时间的方向；备用金排除定期存款方向。
- 稳健及备用金按风险升序，其他偏好在允许范围内按风险降序，同层级先无约定存期，最后按产品ID稳定排序。历史收益不参与排序。
- 金额以整数分传输，范围100–10000000000分；期限为1–120整数月，服务层和HTTP入口均校验。
- `POST /api/finance/recommendations` 复用现有会话、CSRF及同源保护，响应为类型化 VO，包含请求偏好、生成时间、来源、区间、候选、排除理由与规则。
- `FinanceRecommendationController → FinanceRecommendationService → FinanceDataProvider`。本地数据无持久化需求，因此无需 Mapper、数据库迁移或模型调用。未来真实只读源可实现 `FinanceDataProvider`，需先核实官方字段、权益和数据展示约束。

请求示例（金额为分；浏览器页面会自动建立会话并附带 CSRF）：

```json
{
  "riskPreference": "CONSERVATIVE",
  "purpose": "PLANNED",
  "liquidity": "FLEXIBLE",
  "amountMinor": 1000000,
  "horizonMonths": 12,
  "capitalProtection": false
}
```

该请求匹配示例活期存款、货币基金、短债基金与纯债基金；定期存款因灵活取用要求排除，混合/指数基金因风险及期限排除。

## 2026-10-28 点击故障修复

确定复现的缺陷是初始化耦合：金融按钮原先等待审计、用户资料和动作恢复全部成功，这些无关请求任一失败都会使推荐按钮持续禁用。另以旧版 `app.js` 配合新版HTML复现了金融导航不响应；这说明混合缓存可造成同样症状，但没有直接读取用户浏览器缓存，因此不能断言用户实际命中了该缓存。
