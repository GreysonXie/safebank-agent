## 结果

| 检查 | 结果 / 证据范围 |
|---|---|
| setup重复执行 | 同专用库连续setup两次成功 |
| interrupt | 假本地查询后进入缺月等待，checkpoint保存节点位置 |
| 新进程恢复 | 前一Python子进程结束后，新子进程用同thread补参，得到九月结果 |
| 已完成图重复resume | 同thread重复resume没有重复该图查询或本地回答节点 |
| pending writes | 一个并行节点成功、另一个注入失败；新进程恢复后成功节点计数仍1，失败节点计数2 |
| 旧版本拒绝 | 应用侧stub验证旧版本，非真实Java网关验证 |
| 已保存effect结果复用 | 单独throwaway wrapper保存结果，重复读取不新增fake HTTP和假预算计数 |
| SENDING后、发送前故障 | 保守标UNKNOWN，不发送、不退已用假预留 |
| HTTP后、结果保存前故障 | fake服务收到请求，恢复未重发，UNKNOWN可查询 |

假HTTP总发送2次，假预算预留3次；包括一次SENDING之后但尚未发送的故障预留。保守处理可能浪费额度，不能声称每个预留都收到响应。两条澄清图分别为正常恢复与旧版本拒绝，汇总statement_query计数2；正常图本身重复恢复时计数1。

## 环境处理与限制

环境阶段遇到沙箱执行/网络限制，经工具批准后在独立虚拟环境下载依赖。MySQL Windows启动器在当前中文路径下截断路径参数，实验运行文件转入另一个已允许写入的ASCII目录后启动成功：`<LOCAL_PATH>`。仅实验文件移动，旧版库/产物未动。后续本机MySQL服务运行目录采用ASCII路径，代码仓库可以继续原中文路径。

进程仅监听127.0.0.1:3307，专用库safebank_checkpoint_probe_v07，凭证随机生成并仅留本机私有文件。实验DB连接使用本地自签名TLS且未验证服务器身份，仅合成实验，不作为生产TLS方案。检查点/假服务过程没有外部模型请求。

实验脚本位于忽略目录`.superpowers/v07-checkpointer-probe/probe.py`，SHA256 `DE2FB0E8F1A852A1DDAF32F2D7DE74F8292068EFB064996041E9D513F90AD6C0`；明确throwaway，不直接搬入生产。过程中的故障为可控异常，非数据库崩溃、断电或真实供应商故障；effect wrapper单独验证，未证明graph与effect在真实杀进程下的原子一致性。异步Saver、全量conformance、多实例、真实JavaACK、grant续签及整个业务迁移均未验证。
