## 使用入口

打开 [8096 工作台](http://127.0.0.1:8096/)。左侧选择业务，中间展示业务内容及确认卡，右侧输入对话；手机端对话在下方。

“模型已配置·未验证”表示读取了配置但尚未获得有效供应商响应；收到响应才显示连接已验证，二者都不是回答正确率承诺。发送问题、快捷建议和重试可能消耗额度，本轮免费排练不使用这些按钮。

1. 账单：当前表格来自最近返回的数据。九月支出 5,369.33 元、八月 6,547.92 元；九月维修为 9 月 10 日设备维修 2,000 元。净结余与支出不同，退款计入入账，不抵减这里的支出。
2. 代扣：“代扣管理”→具体商户“预览撤销”→核对参数→勾选模拟验证→“确认并执行”。以最终银行回执为准；撤销授权不增加余额、不等于终止商户合同。
3. 转账：“常用工具”→明确选择张三·尾号3271·同学→填 500.00 元→生成预览→核对并勾选→执行。成功后可刷新及查原动作。
4. 储蓄和审计：任务需分别核验各动作。“实验与审计”的模拟触发会改变合成余额，四分钟主脚本无需触发。

UNKNOWN / 银行处理中时查询原 action_id，避免生成同一笔新转账；明确失败时先读错误和原参数，不把失败或未知描述为完成。

## 启动与重置

Java 队员负责运行环境。仓库目录 `D:\2.临时消息文件\研一\深金赛\safebank-agent`，Java 21，使用现有 setup.ps1 / run.ps1。密钥只留本机配置，交接材料不含 apikey.txt。

已有实例直接使用；端口空闲时启动：

```powershell
Set-Location -LiteralPath 'D:\2.临时消息文件\研一\深金赛\safebank-agent'
.\start-online.ps1 -Port 8096
```

此前执行过模拟转账或撤销，由 Java 队员确认要清空当前合成内存状态后运行：

```powershell
.\start-online.ps1 -Port 8096 -ReplaceOwned
```

这会替换脚本登记的本项目实例并恢复初始数据，已有内存动作与回执消失；刷新不重置数据。无需删除数据库或结束其他 Java 进程。启动不发起模型调用。

免费核心验收使用 8097、独立六个月合成库、空模型密钥，结束后关闭自己的进程；8097 被占用则报错。报告和截图在 target/demo-candidate-qa/：

```powershell
& 'C:\Users\21310\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' fixtures/demo-candidate-qa.cjs
```

Node、Playwright、Edge 路径对应当前电脑；队友电脑由 Java 队员调整运行环境路径。脚本验证账单数据、撤销和转账业务，不验证模型追问的智能程度。

## 四人分工

| 角色 | 当前任务 | 交付标准 |
|---|---|---|
| Java 队员 | 接手启动与重置、Controller→Service→MyBatis、动作授权与回执，核对赛题接口要求 | 在本人电脑启动；解释一笔动作从预览到回执；列出官方接口与模拟接口差异 |
| 业务与智能体队员 | 核对账单口径和维修追问，整理典型问题 | 三场景问答清单；每条列依据、缺失信息、正确边界；标注历史/实时来源 |
| 前端与演示队员 | 四分钟排练，检查左导航、中业务、右对话与手机布局 | 完整计时排练和录屏；记录挡住操作的界面问题 |
| 测试与汇报队员 | 维护验收表、调用预算，核对赛题附件、提交形式与评分点 | 一页完成/待验证清单、证据和用量记录，整理答辩材料 |

非 Java 队员通过浏览器、现成报告和 AI 辅助完成交付，无需同时学习后端框架。四人先完成一次联合排练，再由 Java 队员判断问题是否阻塞核心步骤。
