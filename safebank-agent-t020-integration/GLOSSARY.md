# SafeBank 业务术语

**任务（Workflow）**：用户的一项财务目标及其相互依赖的业务步骤。
_Avoid_：把任务等同单笔交易。

**动作（Action）**：一项对象、金额或时间等关键参数明确的银行操作。
_Avoid_：把工具调用本身称作完成。

**动作授权**：用户对一项具体动作及其关键参数的同意。
_Avoid_：把登录、身份验证或笼统同意等同动作授权。

**银行侧代扣撤销**：终止一项银行扣款授权。
_Avoid_：商户退订、合同终止、退款。

**预计月度节省**：基于已核验撤销、且明确按月扣费的项目估算的未来支出减少。
_Avoid_：当前余额增加、已经收到退款。

**已核验成功**：有与动作关键参数相匹配的银行完成证据。
_Avoid_：请求受理、模型说成功。

**状态未知**：无法确认银行是否完成该动作。
_Avoid_：已失败、可以重新创建交易。

**部分成功**：任务中有步骤完成，也有步骤失败或未完成。
_Avoid_：整个任务成功、自动回滚。

**定时任务登记**：一项未来资金委托已生效。
_Avoid_：本期转账成功、未来各期都已完成。

## 对话、规划与治理

**业务会话（Conversation）**：围绕用户需求持续进行的一段对话，可以包含多轮交流。
_Avoid_：与网页登录状态（Session）或单次请求混为一谈。

**对话轮（Turn）**：一次用户输入及对该输入的处理结果；结果可以是追问、回答或待确认预览。
_Avoid_：把一轮对话等同一次模型请求或一次银行动作。

**模型请求（Model Request）**：向模型供应商实际发送的一次请求。
_Avoid_：把模型请求次数等同对话轮数或人民币费用。

**意图提案（Intent Proposal）**：对用户想做什么的结构化解释，尚不构成银行授权。
_Avoid_：把模型提议当作用户已经确认。

**业务任务图（Task Plan）**：表达业务步骤与前置依赖的无环计划。
_Avoid_：与处理对话的流程图混称；与已有任务（Workflow）建立联系，而非创造另一份业务终态。

**业务步骤（Task Step）**：任务中一个有明确输入、前置条件和结果的业务单元。
_Avoid_：把发送工具请求等同步骤已成功。

**能力令牌（Capability Grant）**：在限时、限范围和限次数内调用受控工具的凭证。
_Avoid_：把内部服务通行证当作用户对资金操作的授权。

**证据（Evidence）**：有可核查来源、数据时点和口径的事实记录。
_Avoid_：把模型措辞、用户猜测或过期快照当作完成证据。

**事实核验（Grounding）**：检查回答中的事实声明是否得到相应证据支持。
_Avoid_：把数字有来源等同整段解释的业务含义正确。

**预算限制（Budget Limit）**：对调用次数或费用资源设置的上限。
_Avoid_：与异常行为导致的安全锁定混称。

**行为锁定（Security Lock）**：因连续验证失败或明确可疑行为，暂时限制特定操作。
_Avoid_：把普通查询失败、模型格式错误都视为用户恶意行为。

**外部市场数据（Market Evidence）**：来自授权第三方的行情、产品资料、财务或公告事实。
_Avoid_：与银行交易回执、本人持仓或资金到账证明混称。
