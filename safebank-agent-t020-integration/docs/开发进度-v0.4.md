## 本轮实现

- 接收正常文字及answer_customer回答，不统一覆盖成工具摘要；追问不重述完整账单。
- 保留最近四轮完整会话及有限账单证据，承接月份和交易指代；切换用户清除上下文。余额、授权及计划状态须重新查询。
- 稳定事实ID核对金额、日期、币种及来源；程序补充类别均值、大额占比、明确月付合计及日历常量。
- 受控计算支持同单位加减、平均、比例，及保留首项单位的标量乘除；季度金额折算月均不等于实际月度扣款，无银行写权限。
- 预算与减少比例可作为显式假设，必须在数值所在分句披露；引用及计算产物保留假设来源，不能变成“实际支出”。
- 数值核验后再进行同模型独立请求的只读业务语义审核，检查归因、范围、比较方向、周期与问题焦点；失败反馈交回模型修正，降级不计为正常对话。审核不能调用银行工具，不证明绝对正确。
- 已查过授权的会话每轮由程序刷新当前用户的状态，证据通过contextResults返回，不清空已有账单面板；季度月均为明确预算折算字段。
- 确认卡、逐动作授权与银行回执由程序控制；页面显示可展开查询依据，追问不清空已有账单面板。
- 对未知周期混入月度节省增加有限检查；类别排名由程序计算后提供给模型，避免用宽泛正则判断自然语言主语。仍非完整语义验证。
