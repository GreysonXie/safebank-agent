## 实现结果

- 抽出ModelClient，配置与有效连接验证分别显示；HTTP401、超时、非法响应不暴露原始认证信息。
- 银行适配提供明确拒绝、执行后丢失响应、先受理后完成、查单不可用，按action_id持久化；默认关闭实验故障。
- ActionExecutionService保存提交意图与应用观察。UNKNOWN先查单；只有银行明确证明未受理才恢复原动作供用户显式重试。
- 工作流持久化账单分析、用户选定代扣、逐步状态、版本、action_id、证据和时间；每步独立授权。
- 正常音乐15＋视频68生成8300分计划；视频明确失败只生成1500分计划；未知结果阻断后续。
- 改参取消旧未提交动作并递增版本；历史已完成动作保留。停止后续任务不撤销银行受理，CANCEL_REQUESTED持续查原动作，核实后CANCELLED。
- 页面恢复任务及回执，可按步骤查看动作、改参、查单继续与停止后续；未来计划登记不冒称转账已经发生。
