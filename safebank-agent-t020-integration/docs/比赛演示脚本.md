## 超时或异常时

动作显示 UNKNOWN / 银行处理中时保留原卡片，点击“查询最新状态”，说明为何不能直接重做。明确失败时展示失败回执与余额，不说执行成功。在线 8096 关闭故障注入，部分失败与 UNKNOWN 可用历史独立合成测试证据说明。

供应商不可用时继续演示数据依据、确认卡、授权和回执，并明确当场对话不可用，不用固定文本冒充实时输出。
