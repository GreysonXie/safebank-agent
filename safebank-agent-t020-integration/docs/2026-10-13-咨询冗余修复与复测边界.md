# 咨询冗余修复与复测边界

## 实现

修复用户要求的两类冗余：只解释或暂不办理时，提示明确禁止主动推销预览卡、邀请办理或介绍授权步骤；保留客户主动询问的操作说明和必要的诈骗、合同风险提醒。仅问收费时不附撤销合同教程，假设性合同解释无银行事实引用时使用general。

回答目录在未询问状态时省略state_label；明确不要重复费用时省略代扣MONEY字段，包括分组中的金额引用。原银行事实、金额、回执与权限不变，月付名单的分类信息仍保留。用户询问状态、有效性或月付名单时保留状态引用。

显示清理只删除紧接完整状态引用的重复前缀，以及特定的“你已表示暂不办理撤销，”意向复述，不删除合同否定或执行风险说明。仅对真实银行行上已有的中文周期说明，兼容两个观察到的说明引用别名：mandate_rows索引与真实rowId.billingDescription。不存在的行、金额或其他引用保持拒绝；记录ANSWER_DESCRIPTION_ALIAS_NORMALIZED事件，整段仍须银行核验。
