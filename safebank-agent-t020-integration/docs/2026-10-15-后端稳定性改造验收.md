## 实现

完整HTTP400/401/403/404/405/413/415/422由受限ModelRequestRejected类型表达，效果日志及有预留记录的model_requests写FAILED，运行错误保留安全状态码。超时、408、429、5xx及其他不确定异常仍UNKNOWN。FAILED效果重入不发送；UNKNOWN效果恢复也不发送。两类运行仍暂停原轮次核对，不自动释放会话、返还未知预留或签发新操作。

Java GatewayCoordinator对已鉴权Python回复给出固定用户说明：明确拒绝提示检查模型、参数或账户；未知提示核对原请求，不能把内部响应正文或任意errorCode直接反射给用户。AGENT_REVIEW_REQUIRED外部错误码与既有状态机不变，保留原轮次权限和确认边界。
