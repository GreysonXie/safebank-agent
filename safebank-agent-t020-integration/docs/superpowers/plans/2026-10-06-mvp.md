# SafeBank 第一版 Implementation Plan

**Goal:** 交付本地可运行的 Java 单后端、三个最小业务场景与安全转账链路。
**Architecture:** Spring Boot 提供 Web/API；H2 文件数据库持久化合成银行数据。BankService 实施事务、授权与幂等；AgentService 只提议受控工具调用。
**Tech Stack:** Java 21、Spring Boot 3.5.6、JDBC、H2、JUnit、原生 HTML/JS。
**Spec:** ../../../../规划1.0.md（项目父目录的修订规划）。
**执行方式:** 当前会话内实施；用户已明确要求按修订规划开发，不再重复询问是否实施。

## 全局约束

- 只运行合成数据和模拟资金；服务绑定 127.0.0.1。
- 缺少模型配置时明确显示离线工具演示，不把规则解析称为 LLM。
- 模型无授权凭证；确认绑定 action_id 与 payload_hash，所有写操作检查归属。
- 操作状态与账务持久化；重试和重启不会重复扣款。
- 本轮为 v0.1，不声称已完成正式赛题适配、真实身份认证或全部 100 例。

## 文件边界

- Application.java / application.properties：启动和配置。
- schema.sql / data.sql：持久化表与合成种子。
- BankService.java：查询、预览、授权、提交、查单、代扣和调度。
- AgentService.java：离线演示与可配置模型的受控工具循环。
- ApiController.java / SessionGuard.java：会话、CSRF、输入和错误边界。
- static/index.html / app.js / styles.css：查询、对话、确认与回执。
- BankServiceTest.java / ApiTest.java：金融状态、安全边界和 HTTP 验收。
