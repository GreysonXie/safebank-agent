# SafeBank 工作台视觉升级 · 2026-10-28

用户希望参考 iFinD 示例截图的深蓝数据面板、青蓝色数字和浅色信息区，提升现有工作台的配色与排版。本轮直接更新现有界面，入口继续使用 `http://127.0.0.1:8134/`。

## 改动

- 深海蓝导航与云白工作区，增加导航分组、当前页面青色标识和清晰的页眉；保留原 SafeBank 标志。
- 账单总览使用深色数据面板，真实金额、支出构成和月度趋势采用易区分的青蓝、薄荷及辅助色；交易表保持浅色，方便阅读与筛选。
- 金融推荐增加目标介绍和三步引导，将备用金、近期计划、长期积累整理为场景卡片，统一偏好表单、结果卡片与对比区的层次。
- 右侧对话助手、储蓄、代扣、联系人、卡片和模型设置统一表单、圆角、间距和字体；明确失败、待核实、确认项及高风险状态。
- 1200 像素以上保留导航、业务与对话三栏；较窄桌面把对话移到业务下方，手机端使用顶部横向导航和单列表单。表格可在容器内横向滚动。
- 新增最后加载的 `design.css` 样式层，HTML 保留原业务 ID、场景属性和事件入口。图形装饰为本地 SVG，不包含虚构行情，辅助技术忽略纯装饰元素。
- 全部 13 项本地 JS/CSS 引用使用当前内容 SHA-256 前 12 位版本，避免混用旧资源。

本轮没有调整后端接口、资金授权、数据库结构或推荐筛选算法。金融推荐继续使用明确标注的本地虚构示例，尚未连接 iFinD 真实数据。本轮真实模型请求为 0。
