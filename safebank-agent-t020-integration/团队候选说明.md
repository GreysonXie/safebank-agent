## 在Windows启动

1. 解压到新目录（例如D:/SafeBankCandidate），不要覆盖队友已有.env或数据。
2. 启动Docker Desktop，使用Linux containers；安装Python3.10+。
3. 在解压后的safebank-agent目录打开PowerShell，执行：

```powershell
python deployment/configure.py
python deployment/doctor.py --report .team-local/preflight.json
docker compose up --build -d --wait --wait-timeout 300
python deployment/smoke.py --report .team-local/smoke.json
docker compose ps
```

打开http://127.0.0.1:8134/。本机作者的8136不是队友默认端口。首次构建需联网；此源码包没有捆绑Docker镜像或Java/Python运行时。默认mock免费，不必配置密钥即可测流程。

## 自己配置模型

按deployment/TEAM_README.md编辑自己生成的.env。模型填deepseek-flash，密钥填自己的DEEPSEEK_API_KEY，不要发送或提交.env。旧deepseek-v4-flash仍是官方兼容别名。SAFEBANK_MODEL_SMOKE_CAP是请求次数上限，不是人民币限额；作者本机6元金额护栏不随团队包启用，每人需自行控制账户预算。

2026-10-15检查时DeepSeek官方报告API部分中断、正在修复，生成请求可能超时；先使用mock，不要因超时循环重发。网络恢复后先发一条小请求确认，再做业务验收。参考https://status.deepseek.com/。

## 本次变化和验证边界

新增有限储蓄任务图及进度视图，保留逐动作确认、UNKNOWN查原单和重复请求保护；历史操作默认折叠。已修复引用真实零完成数量的误报，以及任务准备阶段不能声称银行定时委托已登记。读取等待60秒、连接5秒，并保留安全错误类型；不自动重发未知请求。
